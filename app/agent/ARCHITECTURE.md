# 智能体系统架构文档

## 1. 系统概述

本项目实现了一个模块化、可扩展的智能体(Agent)系统，用于执行各种自动化任务。智能体是能够感知环境、做出决策并采取行动的软件实体。系统采用分层架构，从通用基础智能体到特定领域的专用智能体，提供了灵活而强大的智能自动化能力。

## 2. 核心概念

### 2.1 什么是智能体（Agent）？

智能体是一种能够自主执行任务的程序实体，它遵循"感知-思考-行动"的循环：

- **感知(Observe)**: 从环境获取信息
- **思考(Think)**: 分析信息并做出决策
- **行动(Act)**: 执行决策并影响环境

### 2.2 ReAct 范式

本系统基于 ReAct(Reasoning + Acting)范式，将推理和行动紧密结合：

- 智能体先推理出下一步的行动
- 执行该行动并观察结果
- 基于观察结果进行新一轮推理

## 3. 系统架构

### 3.1 智能体继承体系

```
BaseAgent (基础智能体)
└── ReActAgent (推理与行动智能体)
    ├── ToolCallAgent (工具调用智能体)
    │   ├── BrowserAgent (浏览器控制智能体)
    │   ├── MCPAgent (多功能控制面板智能体)
    │   └── ManusAgent (定制任务智能体)
    └── SWEAgent (软件工程智能体)
```

### 3.2 组件职责

#### BaseAgent (`base.py`)

- 所有智能体的基类
- 提供状态管理、记忆功能和执行循环
- 定义智能体生命周期：初始化、运行和清理

#### ReActAgent (`react.py`)

- 实现 ReAct 范式的核心循环
- 将智能体行为分解为观察-思考-行动三步骤
- 提供基本的执行框架

#### ToolCallAgent (`toolcall.py`)

- 扩展 ReActAgent，增加工具调用能力
- 管理工具集合和执行工具调用
- 处理工具返回结果并将其纳入思考过程

#### 专用智能体

- **BrowserAgent** (`browser.py`): 控制浏览器执行网页任务
- **SWEAgent** (`swe.py`): 执行软件工程相关任务
- **MCPAgent** (`mcp.py`): 多功能控制面板集成
- **ManusAgent** (`manus.py`): 特定定制任务处理

## 4. 数据流与控制流

### 4.1 执行流程

1. **初始化**:

   - 加载配置和初始提示
   - 准备工具集合和 LLM 连接

2. **主循环**:

   ```
   while not finished and within max_steps:
       1. 观察环境
       2. 思考下一步行动
       3. 执行行动
       4. 更新状态
   ```

3. **清理**:
   - 释放资源
   - 保存结果和状态

### 4.2 消息流转

智能体通过 Message 对象进行通信:

- **用户消息**: 从用户获取指令
- **系统消息**: 提供背景和指导
- **助手消息**: 智能体的思考结果
- **工具消息**: 工具执行结果

### 4.3 工具调用流程

```
1. 智能体思考 → 选择工具
2. 构建工具调用参数
3. 执行工具调用
4. 获取调用结果
5. 将结果添加到记忆
6. 基于结果继续思考
```

## 5. 关键设计模式

### 5.1 策略模式

- 不同智能体实现不同的思考和行动策略
- 通过继承和多态实现行为定制

### 5.2 中介者模式

- LLM 作为中介协调智能体、工具和环境
- 降低组件间的直接耦合

### 5.3 命令模式

- 工具调用封装为命令对象
- 支持命令的序列化、验证和执行

### 5.4 观察者模式

- 状态变化通知机制
- 支持事件驱动的行为

## 6. 扩展指南

### 6.1 创建新智能体

1. **选择合适的基类**:

   - 一般功能: 继承`BaseAgent`
   - 推理+行动: 继承`ReActAgent`
   - 需要工具调用: 继承`ToolCallAgent`

2. **定义关键组件**:

   - 系统提示词和下一步提示词
   - 可用工具集合
   - 特殊工具处理逻辑

3. **实现核心方法**:
   - `think()`: 决策逻辑
   - `act()`: 行动逻辑
   - `observe()`: 环境感知（可选）

### 6.2 添加新工具

1. 在`app/tool`目录创建工具类
2. 实现必要接口和方法
3. 在智能体初始化时将工具添加到`available_tools`

## 7. 最佳实践

1. **提示词工程**:

   - 使用清晰、具体的提示
   - 分离系统提示和任务提示

2. **错误处理**:

   - 实现健壮的异常处理
   - 优雅地从失败中恢复

3. **资源管理**:

   - 使用异步清理确保资源释放
   - 控制 LLM 令牌使用

4. **测试与调试**:
   - 使用日志跟踪智能体行为
   - 为各组件编写单元测试

## 8. 学习路径建议

1. 从阅读和理解`BaseAgent`开始
2. 学习`ReActAgent`中的观察-思考-行动循环
3. 研究`ToolCallAgent`的工具调用机制
4. 探索特定域智能体的实现
5. 尝试修改现有智能体或创建新智能体

## 9. 核心 API 参考

### 9.1 基础方法

- `BaseAgent.run(request)`: 运行智能体执行任务
- `ReActAgent.observe()`: 观察环境状态
- `ReActAgent.think()`: 分析和决策
- `ReActAgent.act()`: 执行决策的行动
- `ToolCallAgent.execute_tool(command)`: 执行特定工具

### 9.2 重要数据结构

- `Message`: 通信消息基本单元
- `ToolCall`: 工具调用描述
- `ToolCollection`: 工具集合管理
- `AgentState`: 智能体状态枚举
